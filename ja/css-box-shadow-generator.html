            CSS Box Shadow (ボックスシャドウ) 視覚的ジェネレーター
          

          

            ぼかし半径、広がり、X/Y座標、内側シャドウ(Inset)をスライダーで直感調整。リアルタイムプレビューからCSSとTailwindを即座にコピー。
          

        
        
        
          

            CSS グラデーション背景生成ツール (線形・放射状・円錐)
          

          

            線形(Linear)、放射状(Radial)、円錐状(Conic)のCSSグラデーションを直感操作で作成。角度調整、マルチカラー分岐、即座CSSコピー。
          

        
        
        
          

            WCAG 2.1 色コントラスト比チェッカー (AA・AAA アクセシビリティ診断)
          

          

            背景色と文字色のコントラスト比をミリ秒算出。Webアクセシビリティ国際規格WCAG 2.1のAAおよびAAA適合判定を瞬時に表示。
          

        
        
        
          

            PX (ピクセル) ⇄ REM / EM 相互換算ツール (レスポンシブ単位)
          

          

            基準フォントサイズ(16px等)をベースに、PXとREM、EMを双方向でリアルタイム換算。メディアクエリ用のCSSスニペットも自動生成。
          

        
        
        
          

            SVG コード ⇄ CSS Data URI & Base64 背景画像変換ツール
          

          

            SVGソースコードやファイルをブラウザ内で最適化し、CSS background-image用のData URIやBase64形式へ瞬時にエンコード出力。
